# module built by build.sh (dlls.txt). Format:
#
#   <file name> | <status> | <FileDescription>
#

# memory of the file's Properties dialog; no Windows file was available to
# compare while this was written, so a wrong character is possible.

# used (what Explorer shows for a file without a description).
#
# FileVersion and ProductVersion (10.0.19045.3803), ProductName ("Microsoft
# (R) Windows (R) Operating System"), CompanyName and LegalCopyright are the
# same for every module and are set in patches/0007, not here.
# The file is UTF-8 (the registered-trademark sign U+00AE). gen-nowine.py
# applies it to wine-src; the result is patches/0007-windows-version-resources.patch.
