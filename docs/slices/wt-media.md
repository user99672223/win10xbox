# Slice: wt-media

Wine's conformance suites for propsys, windowscodecs, mlang, gdiplus and dwrite (`dlls/<dll>/tests`, Wine 11.9) built as
one PE per DLL by `wine-pe/tests/media.sh --dll <dll>` and run unit by unit through the layer, one gated ctest entry
`integration.winetest_<dll>` each (tests/winetest/CMakeLists.txt), baseline `wine-pe/tests/<dll>.baseline`.

* The earlier commit 9ae3275 (five DLLs in dlls.txt): its wine-pe run 39849544055 built propsys, windowscodecs, mlang,
  gdiplus and dwrite ("built" in the summary table); its ci run 39849544235 failed only on `integration.guest_window_input2`
  (unrelated to this slice). The README stub it added said "work in progress" and is removed.
* `resource.rc` of the gdiplus and dwrite suites (the test fonts `wine_test.ttf`, `wine_testfont0.ttf`, ... ship in the
  Wine sources) is compiled with windres and linked in; no `.sfd` is converted, nothing is generated by hand.
* No fonts are staged in the machine folder's Windows\Fonts: text/font tests are expected to fail and are recorded as such.
