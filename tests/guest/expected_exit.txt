# Expected exit codes of the bundled guest programs under host-uwp (launcher verdict, CI "Assert on report.txt").
# Format:  <program> <code>[=<label>] [<code>=<label> ...] [KNOWNFAIL=<code>:<label> ...]     (# starts a comment; <code> is an integer or TIMEOUT)
# Every listed outcome is a PASS and the verdict names its label: "PASS (exit code 3 = no-input)". A listed program that
# ends with another code is FAIL; one with no row is EXITED/CRASH. TIMEOUT is allowed only where a row lists it.
# KNOWNFAIL=<code>:<label> (a third kind, several allowed) records a failure that is understood and has its own slice: the
# verdict is "KNOWN-FAIL (exit code 2 = label)", counted in the report's knownfail= line, shown in its own colour, never PASS.
# CI allows KNOWN-FAIL only where a row lists it and prints the known-fail programs in the step summary. Any other code is FAIL.
# Codes were observed on the windows-latest runner (host-uwp run 40009489508) and standalone; labels other than the
# first say why the runner/console cannot take the first path.
